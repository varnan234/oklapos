# OKLA-POS website

Static marketing site for OKLA-POS (Chickasha, OK). No build step: Vercel serves `index.html` as-is.

- Edit sections in `partials/`, `css/`, `js/`, then run `bash build.sh` to regenerate `index.html`.
- Design brief: `DESIGN.md`.
- Placeholders to replace: search for `data-placeholder` (phone, email).
- The contact form is not connected to a backend yet.
